## 🚀 Live Demo & Vercel Deployment

This project is optimized for instant **zero-configuration deployment on Vercel**.

### Option 1: Deploy with Vercel Web Dashboard (Recommended - 1 Minute)
1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete portfolio website with resume and project showcase"
   git push origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** ➔ **"Project"**.
4. Select `dina-portfolio` from your GitHub repositories and click **"Import"**.
5. Framework Preset: Leave as **Other** (Vercel automatically detects static HTML/CSS/JS).
6. Click **"Deploy"**!
   Your portfolio will be live at `https://dina-portfolio.vercel.app` (or your custom domain) within 15 seconds.

### Option 2: Deploy with Vercel CLI
If you have Vercel CLI installed:
```bash
npx vercel
# Follow the prompts and select defaults.
# To deploy to production:
npx vercel --prod
```

## 💻 Local Development

No heavy build tools or large `node_modules` required!

### Method 1: Using Node / NPM
```bash
# Start local server on http://localhost:3000
npm run dev
```

### Method 2: Direct Open
Simply double-click `index.html` in Finder to preview in your default browser.
